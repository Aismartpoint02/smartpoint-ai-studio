# SmartPoint AI Studio V26

A unified Next.js frontend for the SmartPoint creator platform.

Included product surfaces:
- AI video production
- Professional timeline editor
- Color/effects workflow
- Audio cleanup/voice workflow
- Captions and subtitles
- Photo studio
- 50-language production
- Live production
- AI Teacher
- Enterprise AI
- Copyright center
- Payments/monetization
- Social publishing
- Cyber-security workspace
- Cloud render/GPU worker architecture

## Run
npm install
npm run dev

## Production check
npm run build
npm start

## Important
The frontend is ready as a deployable product shell. Real AI generation, MP4 rendering, payments, authentication, database, storage and GPU workers require their actual production services and secrets. Do not commit `.env` or provider keys.
